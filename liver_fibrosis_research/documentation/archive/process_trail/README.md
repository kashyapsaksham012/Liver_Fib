# documentation/archive/process_trail/

**Moved here 2026-08-27 during the pre-manuscript documentation cleanup.** Nothing is deleted —
these files are the dated **process trail** of the project: the value is that they exist and are
timestamped, not that anyone reads them front to back.

Every file here is one of:

- a **pre-execution / pre-audit snapshot** (`*_pre_execution_snapshot.md`, `*_pre_audit_snapshot.md`,
  `*preclosure*`, `*pre_modeling*`) — the frozen state recorded before an analysis or audit was run;
- a **decision log** (`*_DECISION_LOG.md`) — the reasoning recorded during a phase;
- a **correction / closure / reconciliation / verification record** (`*CORRECTION_RECORD.md`,
  `*CLOSURE*`, `*RECONCILIATION*`, `*_verification_log.md`, `*handoff*`, `*commit_record*`) —
  housekeeping that confirmed a prior step or reconciled a discrepancy;
- a **superseded phase report** in the BMI-fairness investigation (`PHASE3_AUDIT_REPORT.md`,
  `PHASE4_CORRECTED_REPORT.md`, `PHASE5_FINAL_AUDIT_REPORT.md`, …) — replaced by the one current
  report per phase that remains in `documentation/fairness_bmi_investigation/`.
